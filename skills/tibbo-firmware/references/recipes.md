# Рецепты: готовые программы, проверенные компилятором Tibbo

Каждый рецепт - полный проект TIDE в папке `recipes/<имя>/`: `app.tpr`, `global.tbh`, `main.tbs` (логика),
`device.tbs` (обработчики библиотек). Все рецепты собраны компилятором Tibbo на платформах из таблицы (и компилятором
на Node.js, и облачным - результат одинаковый) и проходят `tibbo_lint.py` без замечаний. Это проверка сборки, а не работы
на устройстве: логику сверяй с задачей пользователя и проверяй на железе.

**Начинай с рецепта, а не с пустого файла:** возьми ближайший, скопируй папку, поменяй константы в начале `main.tbs`.

**Рецепты на Tibbo C (19, 20)** - проект с файлами `main.tc` (`type=c` в `.tpr`) и `global.th` (`type=cheader`). Объекты,
свойства, методы и события те же, что в Tibbo BASIC; синтаксис - C: обработчик `void on_sys_init() { ... }`, вызов метода
со скобками `sock.send();`, строки типа `string`, перечисления в аргументах событий с `enum` (`enum pl_sock_state newstate`).
Компилятор на Node.js Tibbo C не собирает: `tibbo_build.py <папка>` сам уйдёт в TIDE или, с согласия пользователя
(`--cloud-ok`), в облачный компилятор. `tibbo_lint.py` проверяет имена API и в файлах C.

**Что проверено в рецептах 14-18.** Собраны компилятором Tibbo; на устройстве не запускались. Рецепты 17 и 18 повторяют
проекты самой Tibbo (BT-WLN-Echo-Test, CA-TPS2L-LCD-Keypad), рецепт 16 - порядок вызовов TLS из библиотек http и mqtt Tibbo.

## Как пользоваться

1. Скопируй папку рецепта в проект пользователя. Константы (адреса, порты, линии, скорости) - в начале `main.tbs`.
2. **Другая плата из списка «Проверен на»** - поменяй `platform=` в `app.tpr`. **Плата не из списка** или другой набор
   библиотек - создай каркас заново: `python3 scripts/tibbo_new.py <папка> --platform "<плата>" --libs <как в рецепте>`,
   затем перенеси `main.tbs` рецепта и тела обработчиков из его `device.tbs`. Причина: на платах без Wi-Fi не нужна
   библиотека wln, на старых платах объекты fd/kp/lcd включаются строкой `defines=` - генератор это знает.
3. Другой слот Tibbit-а - другие линии и номер порта: `python3 scripts/tps_check.py board "<плата>"` показывает линии
   каждого слота, `tps_check.py check` пишет `ser.num` для каждого последовательного Tibbit-а.
4. Собери: `python3 scripts/tibbo_build.py <папка>` - должно быть «ошибок 0». Потом `tibbo_lint.py <папка>`.
5. Объединяешь два рецепта - у события один обработчик на проект: слей тела `on_sys_timer`, `on_sock_data_arrival` и т.д.
   в один, вызовы библиотек (`*_proc_*`) оставь все. Сокеты раздавай разными номерами (или `sock_get("ИМЯ")` из
   библиотеки sock), `sys.buffalloc()` - один раз после всех запросов буферов.

## Приёмы, которые есть во всех рецептах

- **Ничего не ждёт в цикле.** Работа идёт по событиям; паузы и тайм-ауты - счётчики в `on_sys_timer` (по умолчанию
  каждые 0,5 с, период - `sys.onsystimerperiod` в единицах 10 мс).
- **Буферы:** все `rxbuffrq`/`txbuffrq`/`varbuffrq`, потом один `sys.buffalloc()`. Порт или сокет при этом выключен/закрыт.
- **Не клади больше, чем влезет:** перед `setdata` смотри `txfree`; при приёме бери `getdata(n)` столько, сколько можешь
  передать дальше - остаток останется в буфере, событие придёт снова.
- **`sock.num` / `ser.num` / `io.num` - это «текущий» объект.** В обработчике он уже указывает на источник события;
  если переключаешь - переключай осознанно.
- **Выходы:** сначала уровень (`io.state`), потом `io.enabled = YES` - реле не щёлкнет при старте. Реле и SSR Tibbit-ов
  включены при LOW; линия изолированного входа LOW, когда через вход течёт ток.
- **Общие переменные и процедуры между файлами:** `dim` в одном `.tbs`, `declare` в `global.tbh`. Имена не должны
  совпадать с именами внутри библиотек (ошибка компоновщика «address ... is already defined»).
- **Обработчики библиотек (`callback_*`) в `device.tbs` короткие:** они зовут процедуру приложения из `main.tbs`
  (`app_net_ready`, `app_mqtt_message` ...), а не содержат логику.

## Язык: проверено компилятором

Работает: `byte char word short integer dword long real float string string(N) boolean`, массивы `dim a(3) as byte`,
`dim a, b as byte`, `dim x as byte = 5`, `if ... then ... else ...` в одну строку, `select case` с `case 1, 2:` и
`case else`, `for/next`, `while/wend`, `do/loop while`, `exit for/sub/function`, `goto метка`, `and or not xor mod shl shr`,
`&hFF` `&b1010`, склейка строк `+`, функции `str lstr val lval hex chr asc len left right mid instr(от, где, что, какое)`,
`doevents`. Значение функции - присваиванием её имени. Вызов процедуры без скобок допустим.

Не работает (ошибка компиляции): `elseif` слитно, `return`, `print`, `sleep/delay`, `x += 1`, `!= && || ==`, `&` для
строк, типы `int double single bool`, строка длиннее 255, рекурсия, вызов обработчика события как процедуры, запись в
свойство только для чтения. Компилятор **не** сообщит: обработчик с выдуманным именем события (его просто никто не
вызовет - лови `tibbo_lint.py`), строку, не влезшую в `string(N)` (молча обрежется), ожидание в пустом цикле.
