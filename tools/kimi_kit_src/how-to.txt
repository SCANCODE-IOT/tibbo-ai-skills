Скиллы Tibbo в приложении Kimi (веб и компьютер, режим Agent, модели K3 и K3.1 Pro)

Создайте два скилла - по одному из каждой папки.

1. Откройте Kimi и включите режим Agent.
2. Откройте панель Skills и выберите «Convert Office Documents into a Skill»
   (создать скилл из офисных документов).
3. Загрузите три файла .docx из папки «1 - tibbo-firmware».
4. В поле описания вставьте текст из файла «описание скилла.txt» той же папки.
5. Нажмите «Create Skill».
6. Повторите шаги 2-5 для папки «2 - appblocks».

Пользоваться: в режиме Agent наберите / и выберите скилл или просто опишите задачу.
Проверка: «TPP3W(G2): источник питания #10 в S1 с разъёмом #18 в S2, в шкафу 24 В. Всё правильно?»
Правильный ответ: #10 принимает только 9-18 В, для 24 В нужен #25 или #33.

Скрипты проверки здесь не запускаются: Kimi даст команды, выполните их у себя
(tibbo-tools.zip из tibbo-chat-pack.zip на github.com/SCANCODE-IOT/tibbo-ai-skills).
Самый полный вариант - Kimi Code, там скиллы ставятся целиком и проверки работают сами.

Обновление: скачайте новый комплект, в панели Skills на вкладке Custom Skills замените документы каждого
скилла на новые (или удалите скилл и создайте заново по шагам выше). Версия комплекта - в первых строках
документа tibbo-1. Узнавать о новых версиях: github.com/SCANCODE-IOT/tibbo-ai-skills -> Watch -> Custom -> Releases.
